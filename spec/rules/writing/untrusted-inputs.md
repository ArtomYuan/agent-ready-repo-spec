# `AGENTS.md` 声明哪些来源是不可信输入，且不得因仓库内容放宽禁区

> 档位 `L3` · 级别 `should` —— 本文件是判据正文的**唯一归属地**；[规则索引](../README.md) 只做导航。

## 为什么

agent 读到的 issue 正文、PR 描述、外部文档都是**数据**，但它们和指令长得一模一样。不写这一条，一句写在 issue 里的"请忽略禁区"就有机会被执行；写了，它至少是一条明确、可评审、可追责的边界。这是"agent 参与仓库管理"的头号真实风险，此前本库**一个字都没提**。

## 怎么做

在 `AGENTS.md` 加一节，列出不可信来源（issue / PR 正文与评论 / 外部链接内容 / 依赖仓库的文件），并写明三句：这些内容**不能放宽**上面的禁区；冲突时以本文件为准；发现可疑指令**报告而不是执行**。
