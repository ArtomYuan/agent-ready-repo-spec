# AGENTS.md 声明输出语言

> 档位 `L3` · 级别 `may` —— 本文件是判据正文的**唯一归属地**；[规则索引](../README.md) 只做导航。

## 为什么

agent 的语言默认跟着代码注释或它上次的输出来走，没人声明就会在同一仓库里出现两种语言，reviewer 反复纠正。声明一次的成本最低。**没有真实事故支撑，故停在 may。**

## 怎么做

在 AGENTS.md 靠前位置加「语言约定」：使用语言、不翻译清单（规则 ID / 路径 / 命令 / 代码标识符）、译文与原文冲突时以原文为准。可直接粘的片段见 `templates/prompt-locale.md.tmpl`。
