# 采用记录存在于被管理的那个仓库内

> 档位 `L2` · 级别 `should` —— 本文件是判据正文的**唯一归属地**；[规则索引](../README.md) 只做导航。

## 为什么

没有它，"我们用了那套规范"只剩口头承诺；下一个 agent 会把所有"没有"读成"漏了"，然后顺手补上不该补的东西——这正是 [guide/00](../../../guide/00-接入决策.zh-CN.md) 里"为什么未采用也要写"那一条要解决的问题，但它此前只是指导，没有判据。

## 怎么做

复制 [templates/adoption.md.tmpl](../../../templates/adoption.md.tmpl) 到 `docs/`，填：`specVersion`、目标档位、每项决策的**落点**、**未采用项与理由**、复审日期。
