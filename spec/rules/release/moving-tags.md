# 移动 tag 要留痕（旧 SHA / 新 SHA / 原因），且优先发更正版本

> 档位 `L2` · 级别 `should` —— 本文件是判据正文的**唯一归属地**；[规则索引](../README.md) 只做导航。

## 为什么

tag 可以被移动，而钉住它的人会**静默**拿到另一棵树——这是没有 diff 可读的破坏性变更，比改代码更隐蔽。

## 怎么做

能发 `1.4.1` 就别动 `1.4.0`；确实要动，就把三个值同时写进 Release 正文与 CHANGELOG。程序见 [guide/06](../../../guide/06-信息该放哪.zh-CN.md) §2.5。
