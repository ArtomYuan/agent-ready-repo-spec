# 版本号变更要写明升了哪一位、为什么

> 档位 `L2` · 级别 `should` —— 本文件是判据正文的**唯一归属地**；[规则索引](../README.md) 只做导航。

## 为什么

裸的 `1.5.0 → 1.6.0` 不可验证：读者无法判断这批改动该是 minor（新增 `should`）还是 major（收紧判据）——**这句话是唯一能让版本号被检查的东西**。本库的 SemVer 策略此前只写在 [spec/README.md](../../README.md)「版本策略」里，清单引用数 **0**，与 `R064`–`R069` 是同一处漂移。

## 怎么做

在 CHANGELOG 版本节或发布提交信息里加一句，例：`1.5.0 → 1.6.0：全是新增 should/may，按策略属 minor`。落点要**比 PR 描述活得久**。见 [guide/06](../../../guide/06-信息该放哪.zh-CN.md) §2.2。
