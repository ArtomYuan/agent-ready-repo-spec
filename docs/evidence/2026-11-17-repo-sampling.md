# 证据 · 十个仓库的形态采样

- **采集时间**：2026-11-17
- **方法**：GitHub REST API（`contents` / `git/trees?recursive=1` / `releases` / `community/profile`），用有 `repo` scope 的 classic token
- **样本**：`cli/cli`、`github/docs`、`actions/checkout`、`vercel/next.js`、`rust-lang/rust`、`python/cpython`、`microsoft/vscode`、`anthropics/claude-code`、`modelcontextprotocol/servers`、`sindresorhus/got`
- **复现**：
  ```powershell
  $h = @{ Authorization = "Bearer $env:GITHUB_TOKEN"; Accept = 'application/vnd.github+json'; 'User-Agent'='audit' }
  Invoke-RestMethod "https://api.github.com/repos/<owner>/<repo>/contents/" -Headers $h | % name
  ```
